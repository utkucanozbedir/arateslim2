UTKU CAN ÖZBEDİR — MİMARLIK PORTFOLYOSU
==========================================

Açmak:
1. ZIP dosyasını klasöre çıkar.
2. index.html dosyasını tarayıcıda aç veya klasörü VS Code ile açıp Live Server kullan.
3. Ana sayfadaki proje kartları bu klasördeki ayrı HTML sayfalarına gider.

ÖNEMLİ:
- Bütün bağlantılar yerel ve göreli dosya yollarıdır. Hiçbir bağlantı başka bir siteye, Aysu için hazırlanmış siteye veya harici bir adrese yönlendirme yapmaz.
- Görseller, yüklediğin 3 sayfalık PDF portfolyonun sayfalarından alınmıştır.
- PDF'te yalnızca 2. sayfada restorasyon paftası, 3. sayfada Mimari Proje 1 ve Mekân Organizasyonu paftası bulunduğundan, sayfa içeriği mevcut kaynağın gösterdiği kapsamla sınırlıdır.
- Yeni proje görsellerini eklemek istersen images klasörüne koyup ilgili HTML sayfasındaki görsel yolunu değiştirebilirsin.
